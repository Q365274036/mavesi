# 闲鱼运营发帖

## 核心理念

**两步入池**：文案配图 → 发布。不纠结素材库，素材库作为可选增强，不存在时直接跳过。

## 快速发帖流程（默认模式）

### 第一步：确认 CDP 在线 + 生成文案配图

**不做多余的大模型调用**，直接用 shell_executor 检测端口：

```powershell
# 检测 CDP 端口是否在线
Get-NetTCPConnection -LocalPort {port} -ErrorAction SilentlyContinue | Where-Object State -eq Listen
```

- 在线 → 继续
- 不在线 → 按 xianyu-base 的「自检流程」拉起 Edge + 注入

**文案生成**：根据用户给的主题，AI 直接生成纯文本文案（禁止 emoji 及【】# 等特殊符号，用换行分段）。价格根据服务类型合理设定。

**配图生成**：用 Python Pillow 生成 800x800 大字报封面图，保存到临时目录。代码一次写完，一次 python_executor 执行完毕，不拆分。

### 第二步：一次派发 browser-agent 发布

把**完整文案 + 配图绝对路径 + 价格 + 分类**一次性写入 `current_task`，派发给 browser-agent 连对应 CDP 端口 → goofish.com → 点击"发闲置" → 填写表单 → snapshot 验证 → 提交。

task 模板：
```
通过 CDP {port} 连 Edge，打开 goofish.com，点击"发闲置"发布商品。

标题：{标题}
描述（纯文本逐行输入，禁止 emoji 和特殊符号）：
{完整描述}

价格：{价格} 元
分类：其他技能服务
发货：无需邮寄
配图：{配图绝对路径}

发布前 snapshot 验证：标题无乱码、描述完整、图片加载、价格分类正确。确认后提交。
```

### 第三步：返回帖子链接

browser-agent 发布成功后返回商品链接。发布失败则报告阻塞点。

## 核心规则

### 频率与排期

| 规则 | 值 |
|------|-----|
| 每个号每日发帖上限 | 2 篇 |
| 同 IP 多号发帖间隔 | ≥ 30 分钟 |
| 同一号发布间隔 | ≥ 2 小时 |
| 禁止发帖时段 | 02:00 - 06:00 |

### 防污染

- 每次发帖全新 browser-agent，不传 `inherit_agent_id`
- task 内写死完整文案 + 配图路径 + CDP 端口

### 文案规范

- 纯文本，禁止 emoji 及【】# 等特殊符号
- 用换行分段
- 分类"其他技能服务"，无需邮寄
- 价格根据服务类型合理设定
