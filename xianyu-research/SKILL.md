# 闲鱼调研

## 职责

每天自动采集 100 个同行优质帖子，按号 + 日期 + 项目类型归档为可检索素材库，保留 20 天。

三个号各自独立采集，素材库互不混淆。号2/号3后期换项目方向时，历史素材按号保留不受影响。

## 采集流程

### 第一步：搜索采集（每日执行）

1. 用 browser-agent 连 CDP 端口，在闲鱼搜索页依次搜以下关键词：
   - "Skill定制"、"Agent工作流"、"自动化脚本"、"Python脚本"、"数据采集"、"网页爬虫"
   - "API开发"、"数据分析"、"程序代写"、"软件定制"、"效率工具"、"办公自动化"
2. 每个关键词浏览前 20~30 条结果，按 **想要数从高到低** 排序取前 100 条
3. 每个帖子采集：

| 字段 | 内容 |
|------|------|
| 标题 | 完整标题原文 |
| 价格 | 标价 |
| 浏览量 | 浏览数 |
| 想要数 | 想要/收藏数 |
| 描述文案 | 完整描述原文 |
| 标签 | 帖子标签词 |
| 图片 | 点开大图逐张下载原图（.jpg），不进截图，直接取图片 src |
| 卖家昵称 | 保留供追溯 |
| 帖子链接 | 保留供追溯 |

### 第二步：归类归档

1. 根据标题+文案关键词自动判定项目类型，映射规则：

| 关键词 | 归类 |
|--------|------|
| Skill/工作流/Agent/自动化 | `Skill定制` |
| 脚本/Python/爬虫/采集 | `自动化脚本` |
| 数据/报表/分析/BI | `数据分析` |
| API/接口/后端/开发 | `API开发` |
| 软件/系统/平台/工具 | `软件定制` |
| 其他 | `其他服务` |

2. 每个帖子在对应类型目录下创建 `post_NNN` 子目录
3. 写入 `info.json`，保存所有图片为该目录下的 `01.jpg 02.jpg ...`

### 第三步：生成索引

每日采集完成后生成 `_index.json`：

```json
{
  "date": "2026-08-05",
  "total": 100,
  "categories": {
    "Skill定制": 25,
    "自动化脚本": 30,
    "数据分析": 15,
    "API开发": 12,
    "软件定制": 13,
    "其他服务": 5
  },
  "top_10_wanted": [
    {"title": "...", "category": "Skill定制", "wanted": 328, "path": "Skill定制/post_001/"}
  ]
}
```

### 第四步：自动清理

每次采集完成后检查，自动删除 **超过 20 天** 的日期目录。

## 图片采集规则

- **必须原图**：点击图片进入大图模式，通过 CDP 获取 `<img>` src 直接下载，不用截图
- **无水印**：下载前检查图片 URL，优先获取原始尺寸版本
- **命名**：按帖子内显示顺序 `01.jpg 02.jpg ...`，最多 9 张
- **存储**：放在 `post_NNN/` 目录下，与 `info.json` 同级

## 素材检索

发帖需要素材时，按以下方式检索：

1. **按类型找**：直接进对应分类目录，看最近的帖子
2. **按爆款找**：读当日 `_index.json` 的 `top_10_wanted`，快速定位高热度帖
3. **按关键词找**：在 `_index.json` 中搜索标题关键词
4. **跨日期对比**：看了几天的 `_index.json`，分析趋势变化

## 多号采集规则

三个号可按不同方向独立采集，也可错时共用同一套关键词：

| 号 | 采集方向 | 执行时间 |
|---|---------|---------|
| 1 | Skill定制 / API开发 / 自动化脚本 | 上午 10:00 |
| 2 | 自动化脚本 / 数据采集 / 软件定制 | 上午 10:45 |
| 3 | 数据分析 / 效率工具 / 办公自动化 | 上午 11:30 |

错时 ≥ 30 分钟（同 IP 多号规则）。

## 每日执行建议

- 执行前先确认对应号的 Edge 已登录且 CDP 端口可用
- 单次采集耗时约 30~45 分钟
- 登录时如遇账号选择页，按 CDP 端口对应关系选择匹配账号（详见 xianyu-base 账号选择处理）
